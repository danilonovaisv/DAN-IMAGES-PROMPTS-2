# Frontend Specialist

## Scope

Own `src/features/`, `src/components/`, `src/index.css`, and browser behavior. Coordinate API contract changes with the API Domain Specialist.

## Responsibilities

- React state, interaction ergonomics, responsive layout, accessibility, and Motion behavior.
- Preserve the visual library workflow and human review before persistence.
- Reuse `ApiService`, domain types, Lucide, and existing styling patterns.
- Verify loading, empty, error, success, keyboard, and reduced-motion states.

## Handoff

Return changed surfaces, checks run, screenshots or interaction evidence when relevant, and residual UX risks. Do not change server persistence or provider logic without coordination.
